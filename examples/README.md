# 最小网页联调入口

这些网页是可选测试资源，不是 HAR 运行依赖，也不会自动发布或替换候选小程序。

- `line/index.html`：官方 LIFF SDK 初始化、真实环境显示、登录、扫码。直接调用 API，不使用 `inLineClient` 阻止扩展测试，不更改客户端状态。
- `vk/index.html`：官方 VK Bridge 初始化、扫码和振动。

在自己有权限配置的 LIFF / VK 测试应用中，将对应网页作为 HTTPS Endpoint。LINE 用 `?liffId=真实ID` 提供公开标识，并在宿主目录设置相同 ID；如 Endpoint 有自定义 query，保持其回跳配置一致。VK 必须从官方 `/app<ID>` 入口加载网页 iframe。

本目录仅提供 HTML，可由自己的静态服务托管；创建应用、修改平台控制台或发布托管不由迁移脚本自动执行。两个页面依赖公开 SDK 分发地址及网络可达性。页面只显示扫码、振动及环境信息，不读取或显示登录 Token、用户资料或密码。

当前 LINE Debug 宿主已有内嵌扫码诊断面板，可先用该面板联调，不必先部署新页面。网页部署不属于本次已执行的验证结果。
