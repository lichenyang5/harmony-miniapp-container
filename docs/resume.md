## 简历推荐版

**HarmonyOS 多厂商 H5 小程序容器集成与原生能力桥接**

技术栈：ArkTS / ArkUI / ArkWeb / HAR / JavaScript Bridge / Hvigor / OHPM

基于已有 AtomicMPSDK，开发 HarmonyOS 普通 HAP 宿主，通过独立 HAR 加载选定 LINE/VK 小程序，完成网页 API 到扫码、振动等原生能力的调用及回包闭环。

- 实现配置驱动的小程序目录、厂商 ID/URL 校验、启动参数白名单与 Adapter 接入，完成容器返回、刷新、关闭及应用级生命周期接入。
- 打通源码 HAR 构建、二进制 HAR 消费和签名 HAP 真机部署；编写 Windows 构建脚本，完成本地签名隔离、依赖切换检查与构建失败恢复。
- 联调 LINE WEB 扫码、VK 扫码与振动，验证成功、扫码取消重试及 VK 振动非法参数回包；针对 LINE 测试台的客户端前置条件，增加调用真实 API 的 Debug 诊断入口。
- 组合继承测试与新增测试，建立 44 项迁移回归；完成真机前后台恢复和 10 轮快速挂载关闭验证，维护分层验收记录与兼容边界。
- 接入真实 VK 壁纸用量计算小程序，完成已有登录态下的参数操作、计算结果、二维详情、宿主/系统返回、关闭释放与历史恢复验证，形成业务演示流程。

LINE 业务补充（可替换上一条或面试展开）：接入真实 LINE 天气小程序，完成地区搜索、偏好保存、预报切换、刷新恢复及导航退出验证，将业务承载演示与原生扫码测试分开呈现；本次未要求登录，不宣称账号认证通过。

## 简历压缩版

**HarmonyOS 多厂商小程序容器集成**：基于已有 SDK 开发 ArkTS 宿主，完成独立 HAR 打包与消费、LINE/VK 适配接入及导航生命周期处理；真机验证 LINE 扫码、VK 扫码/振动与对应回包，并接入 VK 计算工具与 LINE 天气业务，验证选定业务操作、导航退出和重开恢复，建立 44 项迁移回归和可复现构建流程。

## 约一分钟的口述

这个项目解决的是在一个新的 HarmonyOS 应用里，接入已有多厂商小程序 SDK，并证明它能以独立 HAR 交付和运行。我主要负责新宿主、HAR 构建与依赖切换、导航和生命周期接入，以及网页到原生能力的联调和验证。

实现上，宿主读取配置并校验厂商 ID 和官方 URL，再为 LINE WEB 或 VK 选择对应 Adapter。网页调用通过 SDK 的厂商代理进入原生 Handler，完成后按厂商格式回传结果。已有协议框架和会话机制来自原 SDK，我没有在本次迁移中从零重写。

目前两个平台的真实 API 测试小程序已经能加载；LINE 扫码、VK 扫码和振动都有真机结果，也验证了取消重试、非法参数和容器关闭重建。另接入 VK 壁纸计算工具和 LINE 天气服务，分别验证已有 VK 登录态下的计算流程，以及无需登录的天气查询与偏好恢复；业务算法和数据属于第三方，我负责容器承载和联调。典型问题是 LINE 测试台检查官方客户端环境，我通过 Debug 面板调用真实 API 来验证 WEB 扩展能力，没有伪造客户端标志。

## 面试时值得展开的三个点

1. **独立交付**：为什么源码模块能编译还不够；如何证明宿主实际使用打包 HAR；切换失败如何恢复。
2. **协议联调**：LINE 和 VK 的成功/取消/非法参数语义如何分别验证；为什么网页显示、SDK 日志和系统页面需要相互印证。
3. **生命周期**：宿主在哪初始化 SDK，返回键如何交给导航控制器，组件退出如何释放会话；哪些异步边界只做了替身回归。

## 不采用的表述

| 不采用 | 有证据支撑的表达 |
| --- | --- |
| 从零研发完整 LINE/VK SDK | 基于已有 SDK 完成 HAR 迁移、宿主开发与选定能力联调 |
| 适配全部 LINE/VK 小程序或全部 API | 跑通两个平台 API 测试小程序、选定原生能力及 LINE/VK 各一个业务工具的具体流程 |
| 已实现元服务上架 | 普通 HarmonyOS HAP 接入独立 HAR，未做上架 |
| 独立新增 44 个测试、全量测试通过 | 组合继承与新增测试，44 项迁移回归通过；原 SDK 其他套件有已记录失败 |
| 十轮完整业务压测、无内存泄漏 | 十轮快速挂载关闭通过；未做长期内存或完整业务稳定性测量 |
| 调用耗时降低到 5ms、性能提升若干倍 | 已验证原生调用与网页回包；没有可用于性能对比的基准数据 |
| 已完成 LINE 登录或所有业务闭环 | LINE WEB 扫码通过，未验证 LINE 登录；VK 官方登录由用户在设备完成 |
| 迁入代码行数等同于个人研发产出 | 按新增宿主、构建流程、诊断与测试职责说明贡献 |
